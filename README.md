# 一生一系统

## 项目简介

西安电子科技大学“一生一系统”实践项目。从数字逻辑开始，逐步学习并构建 RISC-V CPU、外设、操作系统和应用系统，形成一个可持续维护的完整计算机系统工程。

## 总体架构

数字系统设计 → RISC-V 处理器 → 外设接口 → 操作系统 → 应用系统

## 项目进度

| 阶段 | 当前状态 |
| --- | --- |
| 数字电子时钟 | 已完成 Questa 功能仿真验收及 Vivado 初步综合 |
| RISC-V 处理器 | 准备进入 RV32I 指令集学习 |
| 外设接口 | 尚未开始 |
| 操作系统 | 尚未开始 |
| 应用系统 | 尚未开始 |

## 开发工具

目前使用 Verilog、SystemVerilog、Questa 和 Vivado。后续工具随项目实际进展补充。
